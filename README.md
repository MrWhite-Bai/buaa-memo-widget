# BUAA浮光

一个带倒计时、图片附件、事项分组和手机独立版的浮光备忘录。

> v6.0.0 公测正式开始。应用无需内测密钥，下载或打开后即可直接使用。开发者兑换码仍可自愿用于解锁开发者身份。

## 手机版下载选择

扫描浮光“手机版下载”中的固定二维码，或直接打开
[国内平台项目页](https://cysyforum.muzermat.online/cy-platform/projects/5)
并登录。请根据自己的手机选择：

- **安卓手机：** 下载 `BUAA-Memo-Android-v6.0.0.apk`，允许系统安装未知来源应用，安装后直接使用。
- **iPhone / iPad：** 使用 Safari 打开
  [BUAA浮光在线版](https://mrwhite-bai.github.io/buaa-memo-widget/)，
  点击“分享 → 添加到主屏幕”，再从主屏幕打开即可使用。

完整的安卓 APK、iOS 原生源码、macOS 和 Windows 版本位于下方“下载”区域。
国内平台会保留镜像下载入口，GitHub 链接仅作为备用来源。

#### iOS 版当前限制

- iOS 原生版不能直接安装压缩包中的 IPA，必须使用 Apple 开发者证书签名，或通过 macOS 和 Xcode 安装。
- PWA 版需要通过 Safari 的“分享 → 添加到主屏幕”安装，且网站必须支持 HTTPS。
- GitHub Pages 地址需要能够正常访问；部分国内网络环境可能加载缓慢。
- PWA 关闭后不能像 Android 一样执行后台定时通知，也不能持续提供局域网同步。
- iOS PWA 不能自行下载安装新版本；“检查更新”只能载入网页新版或跳转国内平台。
- 清除 Safari 网站数据可能同时删除 PWA 内的本地事项。
- 部分功能受 iOS 系统版本、Safari 设置和省电策略影响。

Windows 版解压后双击 `BUAA浮光.exe` 运行，不需要安装 Python。
电脑版使用与手机版一致的一体化星夜和江面界面，并以独立桌面窗口运行。

## 历史事项

事项到达截止时间或结束时间后，会继续保留在主页 24 小时，并显示距离
自动归档的剩余时间。满 24 小时后会自动进入历史事项。到期后的这 24 小时
内，任务仍可手动标记为完成；主动完成的任务会立即进入历史事项。

## 更新方式

手机端或电脑端点击“检查更新”后，会打开“学业支持中心开源平台”
的项目 5。未登录时需先登录平台，登录后在“版本下载”中获取最新版。
插件不会保存或上传平台账号与密码。

手机版和电脑版联网启动后会优先从“学业支持中心开源平台”检查最新版本。
更新按钮会明确显示“正在检查”“已是最新版”“可以更新”或“检查失败”。
检查失败时可以点按钮重试，也可以直接打开国内平台手动下载。

Android 版检测到新版本后，点击“可以更新”即可在 App 内自动下载并打开
系统安装器。首次更新只需授权一次“安装未知应用”，授权后会自动继续。
同步服务不会在通知栏显示通知，通知栏只保留用户设置的事项提醒。

旧版手机离线 HTML 仍可作为备用方案。

## 事项分组

事项主页是第一个界面，“分组”是第二个界面。可以新建、编辑和删除
分组，并为分组设置名称和简介。编辑分组时可以勾选已有事项加入分组，
新建或编辑事项时也可以直接选择所属分组。删除分组不会删除事项，
组内事项会保留并自动变为未分组。

点击分组中的“查看事项”可以查看组内全部事项的当前状态、剩余时间、
起止时间、备注和图片。手机端还可从详情中编辑仍在进行中的事项。

## Android 独立运行

点击电脑端“手机APP”，手机联网后直接扫描二维码即可打开下载平台，
下载手机版不要求手机与电脑连接同一 Wi-Fi 或热点。登录平台后从
“版本下载”中安装最新版 APK。手机 App 可以独立运行，不需要云端服务器。

只有手机与电脑同步数据时，才需要连接同一局域网或手机热点。同步步骤：

1. 手机和电脑连接同一个 Wi-Fi，或让电脑连接手机热点。
2. 打开 Android 手机版，点击底部鲜艳的“同步”按钮。
3. 记下手机显示的 12 位配对码和 `IP:端口`，并保持页面打开。
4. 在电脑版点击“同步”，输入配对码。
5. 电脑能自动发现手机时无需填写地址；校园网无法发现时，填写手机显示的
   `IP:端口`。
6. Wi-Fi、校园网或手机热点在重连后可能给电脑重新分配 IP；固定端口 `8765`
   和已保存的 12 位配对码通常不会变化。如果旧地址突然连不上，只需更新
   地址中的 IP，通常不需要重新配对。
7. 同步成功后两端数据会合并；任何一端离线时仍会各自保存。

首次配对成功后，电脑会记住局域网地址和同步令牌。手机端显示的同步页面可
用来核对地址和配对码；未授权设备会收到 401 拒绝。
当前事项和历史事项都会进入同步预览。完成、到期迁移和删除历史事项时，
可同步全部变更，也可逐项选择需要应用到另一端的历史记录。

手机版主页提供“电脑版下载”区域，可复制下载链接或通过系统分享发送到电脑。
在电脑浏览器打开链接并登录平台后，即可下载 Windows 或 macOS 版本。

新建手机事项时可设置提前通知，时间单位支持分钟、小时和天，提醒方式支持
通知栏、响铃和振动，并可任意组合。提醒由 Android 系统定时器执行，App
关闭后仍然有效；手机重启后会自动重新安排尚未到期的提醒。

手机锁屏或熄屏时，提前通知会短时点亮屏幕并显示全屏提醒卡片。首次使用
需要在系统设置中允许精确闹钟和全屏提醒；Android 14 及以上系统会由 App
自动打开对应授权页面。

v3.5.2 起，弹窗只负责显示通知，响铃改为内置的柔和双水滴音效并通过
系统闹钟音频通道播放，振动使用闹钟用途属性，不再依赖旧通知渠道的声音
和振动设置。编辑事项时可在“提前通知”区域独立设置 10%–100% 的提醒音量，
并点击“测试当前提醒”，按当前勾选方式触发一次 3 秒后的测试提醒。

v4.4.1 修复了 Android 测试提醒因 WakeLock 锁级别组合无效而闪退的问题。

## Android 局域网好友

v4.5.0 开放 Android 与 iOS 之间的好友内测。底部导航为“事项 / 分组 / 我的”三栏，好友功能集中在“我的”页面。每台手机根据配对码和设备私密密钥生成独立好友码，原始配对码不会作为好友码公开。

“我的”页面支持设置最多 20 个字符的账号昵称。昵称保存在本机，并会通过加密好友消息同步给已添加的好友；好友离线时会在下一次连接或 Android 中继补发时更新。

Android 和 iOS 原生 App 的好友双方需连接同一 Wi-Fi 或热点。输入好友码并发出请求后，对方必须手动确认。好友可以发送端到端加密的文字消息，也可以把单个事项分享给对方。好友离线时，消息保存在发送方待发队列中，双方同时在线后自动补发。iOS PWA 受系统后台限制，不提供独立好友监听服务。

Android 还可以临时充当局域网中继：iOS 离线时，Android 先保存加密消息；iOS 下一次打开并连接同一网络时主动拉取。若 Android 离线，iOS 发出的消息保留在 iOS 本地，直到两端再次同时在线。

Android 14 及以上系统建议保持“闹钟和提醒”权限开启。浮光现在使用高优先级精确闹钟，并会在用户从系统授权页返回后立即重新调度所有未到期提醒，避免提醒被系统延迟到下次打开 App。

Android 首次启动会显示“开启提醒保障”页面，逐项说明并引导开启通知权限、闹钟和提醒、电池不受限制及自启动。未开启时页面会写明提醒延迟或不响的后果；选择稍后设置后，下次启动仍会继续提醒。

电脑版和普通浏览器版暂不启用好友协议，界面会显示功能说明；Android 与 iOS 已使用同一身份和消息格式。

手机周视图采用竖屏三列课程表，今天、明天和后天的 `00:00–23:59`
会在同一屏幕内完整显示，无需上下或左右滚动。

## iOS 版

仓库同时提供原生 iOS Xcode 工程。界面、事项图片、分组、历史事项、周视图、
本地通知和局域网同步均已接入。由于 Apple 要求使用有效开发者证书签名，
iOS App 需要在 macOS 上使用 Xcode 构建，或通过 TestFlight 分发给公测用户。

iOS 会在锁屏显示本地通知，但是否自动点亮屏幕由用户的通知设置和系统版本决定。
iOS 不允许第三方 App 自行下载安装新版本，也不允许像 Android 一样显示全屏
Intent 或让 App 持续在后台提供局域网同步服务。

如果无法加入 Apple Developer Program，可以使用 iOS PWA 静态包。把压缩包内的
全部文件部署到支持 HTTPS 的静态网站，然后让用户在 iPhone Safari 中打开网址，
点击“分享 → 添加到主屏幕”。PWA 数据保存在本机，不需要数据库，也不需要按
用户数量支付服务器费用。

## 等级特权

“我的 → 浮光经验 → 等级特权”会显示当前容量、下一档目标和全部解锁路线。
达到等级后特权立即生效，无需领取：

| 等级 | 特权 | 实际效果 |
| --- | --- | --- |
| 3 | 题签舒展 | 札记标题上限提升至 120 字 |
| 5 / 15 / 30 / 45 / 50 | 同行阶梯 | 好友上限依次提升为 25 / 30 / 40 / 50 / 60 人 |
| 8 | 留白成章 | 札记正文提升至 15,000 字，简介提升至 800 字 |
| 10 / 25 / 40 | 勋章陈列 | 可佩戴勋章依次提升为 4 / 5 / 6 枚 |
| 20 | 签到回响 | 每日签到提升为 8 光斑和 30 经验 |
| 35 | 长卷无界 | 单篇札记正文上限提升至 30,000 字 |
| 50 | 浮光领航者 | 签到提升为 10 光斑和 40 经验，并显示专属称号 |

好友容量会同步写入 Android 与 iOS 原生好友校验。开发者身份仍保持好友数量
无上限，其他用户按当前等级获得容量。等级只增加权益，不会减少已有事项、
札记、分组、勋章或光斑。

## 背包、数量赠礼与艺展道具

同一种物品在背包中只占一个格子，格子右上角显示数量。旧版本遗留的同类
物品会在首次读取时自动合并。使用和赠送都可以填写 1 到当前库存之间的数量，
赠礼邮件会保存实际数量，领取后再次合并到收件人的背包格。

“我的 → 艺展 → 道具”出售以下商品：

- 浮光心意卡：8 光斑，使用获得 6 经验，可赠送。
- 清泉凝露：22 光斑，使用获得 25 经验，可赠送。
- 月白邮封：35 光斑，使用获得 40 经验，可赠送。
- 星辉长笺：60 光斑，使用获得 70 经验，可赠送。
- 改名卡：300 光斑，使用后获得一次立即改名机会，可赠送。
- 星夜盲盒：96 光斑，打开随机获得 40–120 经验，可赠送。
- 鎏金头像框：240 光斑，一次性永久解锁。
- 听雨称号：180 光斑，一次性永久解锁；50 级时优先显示“浮光领航者”。

昵称首次设置后会进入 6 个月冷却。修改窗口会显示剩余天数和最早可修改日期，
提交相同昵称不会消耗冷却。使用改名卡可以跳过一次冷却，只有真正完成改名时
才消耗改名机会，取消修改不会扣除。

## 天气

事项页顶部会显示北京当天的当前温度、天气状态、最高温和最低温。天气数据来自
无需密钥的 Open-Meteo 服务，并缓存 30 分钟。短暂断网时继续显示最近一次结果；
读取失败不会影响事项、札记、同步和提醒，可点击天气栏右侧“刷新”重试。

## 浮光艺展与藏品

“我的 → 艺展”分为四个分类：

- **画廊：** 永久收藏 12 幅梵高与莫奈公版画作，价格 680–980 光斑。
- **画框：** 博物馆开放馆藏边框素材，价格 82–118 光斑，购买后进入背包。
- **信纸：** 对应画作局部画面，价格 24–32 光斑；必须先收藏对应画作才能购买。
- **道具：** 原浮光小铺商品，包括经验物品、改名卡、头像框和称号。

画廊当前包含《星月夜》《鸢尾花》《杏花》《睡莲》《罂粟花田》
《日出·印象》《麦田与柏树》《向日葵》《夜间露天咖啡座》《睡莲池》
《撑阳伞的女人》和《维特尼的花圃》。购得的画作显示在
“我的 → 藏品”，最多同时展示三幅。

事项、札记和分组编辑页可以选择画框；札记和分组还可以选择信纸。
每个事项、札记和分组会永久记住已经使用过的素材：首次使用某个画框或信纸
消耗 1 个，切换到其他素材后再切回之前用过的素材不会重复扣除。
保存失败时会自动退还素材。

画作、信纸局部和画框素材均随安装包离线保存，来源与许可见
`assets/art-gallery/LICENSE.md`。
