# BUAA浮光

#### iOS 版当前限制

- iOS 原生版不能直接安装压缩包中的 IPA，必须使用 Apple 开发者证书签名，或通过 macOS 和 Xcode 安装。
- PWA 版需要通过 Safari 的“分享 → 添加到主屏幕”安装，且网站必须支持 HTTPS。
- GitHub Pages 地址需要能够正常访问；部分国内网络环境可能加载缓慢。
- PWA 关闭后不能像 Android 一样执行后台定时通知，也不能持续提供局域网同步。
- iOS PWA 不能自行下载安装新版本；“检查更新”只能载入网页新版或跳转国内平台。
- 清除 Safari 网站数据可能同时删除 PWA 内的本地事项。
- 部分功能受 iOS 系统版本、Safari 设置和省电策略影响。

Windows 版解压后双击 `BUAA浮光.exe` 运行，不需要安装 Python。
电脑版使用与手机版一致的一体化星夜和江面界面，并以独立桌面窗口运行。

## 历史事项

事项到达截止时间或结束时间后，会继续保留在主页 24 小时，并显示距离
自动归档的剩余时间。满 24 小时后会自动进入历史事项。到期后的这 24 小时
内，任务仍可手动标记为完成；主动完成的任务会立即进入历史事项。

## 更新方式

手机端或电脑端点击“检查更新”后，会打开“学业支持中心开源平台”
的项目 5。未登录时需先登录平台，登录后在“版本下载”中获取最新版。
插件不会保存或上传平台账号与密码。

手机版和电脑版联网启动后会优先从“学业支持中心开源平台”检查最新版本。
更新按钮会明确显示“正在检查”“已是最新版”“可以更新”或“检查失败”。
检查失败时可以点按钮重试，也可以直接打开国内平台手动下载。

Android 版检测到新版本后，点击“可以更新”即可在 App 内自动下载并打开
系统安装器。首次更新只需授权一次“安装未知应用”，授权后会自动继续。
同步服务不会在通知栏显示通知，通知栏只保留用户设置的事项提醒。

旧版手机离线 HTML 仍可作为备用方案。

## 事项分组

事项主页是第一个界面，“分组”是第二个界面。可以新建、编辑和删除
分组，并为分组设置名称和简介。编辑分组时可以勾选已有事项加入分组，
新建或编辑事项时也可以直接选择所属分组。删除分组不会删除事项，
组内事项会保留并自动变为未分组。

点击分组中的“查看事项”可以查看组内全部事项的当前状态、剩余时间、
起止时间、备注和图片。手机端还可从详情中编辑仍在进行中的事项。

## Android 独立运行

点击电脑端“手机APP”，手机联网后直接扫描二维码即可打开下载平台，
下载手机版不要求手机与电脑连接同一 Wi-Fi 或热点。登录平台后从
“版本下载”中安装最新版 APK。手机 App 可以独立运行，不需要云端服务器。

只有手机与电脑同步数据时，才需要连接同一局域网或手机热点。同步步骤：

1. 手机和电脑连接同一个 Wi-Fi，或让电脑连接手机热点。
2. 打开 Android 手机版，点击底部鲜艳的“同步”按钮。
3. 记下手机显示的 12 位配对码和 `IP:端口`，并保持页面打开。
4. 在电脑版点击“同步”，输入配对码。
5. 电脑能自动发现手机时无需填写地址；校园网无法发现时，填写手机显示的
   `IP:端口`。
6. Wi-Fi、校园网或手机热点在重连后可能给电脑重新分配 IP；固定端口 `8765`
   和已保存的 12 位配对码通常不会变化。如果旧地址突然连不上，只需更新
   地址中的 IP，通常不需要重新配对。
7. 同步成功后两端数据会合并；任何一端离线时仍会各自保存。

首次配对成功后，电脑会记住局域网地址和同步令牌。手机端显示的同步页面可
用来核对地址和配对码；未授权设备会收到 401 拒绝。
当前事项和历史事项都会进入同步预览。完成、到期迁移和删除历史事项时，
可同步全部变更，也可逐项选择需要应用到另一端的历史记录。

手机版主页提供“电脑版下载”区域，可复制下载链接或通过系统分享发送到电脑。
在电脑浏览器打开链接并登录平台后，即可下载 Windows 或 macOS 版本。

新建手机事项时可设置提前通知，时间单位支持分钟、小时和天，提醒方式支持
通知栏、响铃和振动，并可任意组合。提醒由 Android 系统定时器执行，App
关闭后仍然有效；手机重启后会自动重新安排尚未到期的提醒。

手机锁屏或熄屏时，提前通知会短时点亮屏幕并显示全屏提醒卡片。首次使用
需要在系统设置中允许精确闹钟和全屏提醒；Android 14 及以上系统会由 App
自动打开对应授权页面。

v3.5.2 起，弹窗只负责显示通知，响铃改为内置的柔和双水滴音效并通过
系统闹钟音频通道播放，振动使用闹钟用途属性，不再依赖旧通知渠道的声音
和振动设置。编辑事项时可在“提前通知”区域独立设置 10%–100% 的提醒音量，
并点击“测试当前提醒”，按当前勾选方式触发一次 3 秒后的测试提醒。

手机周视图采用竖屏三列课程表，今天、明天和后天的 `00:00–23:59`
会在同一屏幕内完整显示，无需上下或左右滚动。

## iOS 版

仓库同时提供原生 iOS Xcode 工程。界面、事项图片、分组、历史事项、周视图、
本地通知和局域网同步均已接入。由于 Apple 要求使用有效开发者证书签名，
iOS App 需要在 macOS 上使用 Xcode 构建，或通过 TestFlight 分发给内测用户。

iOS 会在锁屏显示本地通知，但是否自动点亮屏幕由用户的通知设置和系统版本决定。
iOS 不允许第三方 App 自行下载安装新版本，也不允许像 Android 一样显示全屏
Intent 或让 App 持续在后台提供局域网同步服务。

如果无法加入 Apple Developer Program，可以使用 iOS PWA 静态包。把压缩包内的
全部文件部署到支持 HTTPS 的静态网站，然后让用户在 iPhone Safari 中打开网址，
点击“分享 → 添加到主屏幕”。PWA 数据保存在本机，不需要数据库，也不需要按
用户数量支付服务器费用。

## 数据说明

备忘录数据只保存在用户自己的电脑和手机中，不会上传到本仓库。
本仓库只保存程序、更新清单和公开的通用离线页面。
所有公开发行包都不包含作者的私人事项；离线页下载入口也不会写入个人记录或局域网访问令牌。
