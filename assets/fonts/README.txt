BUAA浮光内置字体说明
====================

应用中的字体别名、实际字体来源和许可证如下：

1. BUAA Song（宋体）
   - 文件：buaa-song.woff2
   - 来源：ZCOOL XiaoWei（站酷小薇）
   - 来源项目：https://github.com/google/fonts/tree/main/ofl/zcoolxiaowei
   - 许可证：SIL Open Font License 1.1
   - 许可全文：LICENSE-ZCOOLXiaoWei.txt

2. BUAA Kai（楷体）
   - 文件：buaa-kai.woff2
   - 来源：LXGW WenKai Lite Regular（霞鹜文楷 Lite）
   - 来源项目：https://github.com/lxgw/LxgwWenKai-Lite
   - 许可证：SIL Open Font License 1.1
   - 许可全文：LICENSE-LXGWWenKaiLite.txt

3. BUAA Hei（黑体）
   - 文件：buaa-hei.woff2
   - 来源：Smiley Sans Oblique（得意黑）
   - 来源项目：https://github.com/atelier-anchor/smiley-sans
   - 许可证：SIL Open Font License 1.1
   - 许可全文：LICENSE-SmileySans.txt

4. BUAA Shoujin（瘦金体）
   - 文件：buaa-shoujin.woff2
   - 来源及许可说明：LICENSE-Shoujin.txt

5. BUAA Script（开场英文花体）
   - 文件：buaa-script.woff2
   - 来源：Allura（Google Fonts）
   - 来源项目：https://github.com/google/fonts/tree/main/ofl/allura
   - 许可证：SIL Open Font License 1.1
   - 许可全文：LICENSE-Allura.txt

以上字体均随应用离线分发，不依赖用户设备是否安装对应字体。
