# BUAA 备忘倒计时

一个带倒计时、图片附件、微信扫码控制和离线同步的 Windows 桌面备忘录。

## 下载

- [Windows 完整版](BUAA-Memo-Windows-v3.4.1.zip)
- [macOS 浏览器版](BUAA-Memo-macOS-v3.4.1.zip)
- [Android APK](BUAA-Memo-Android-v3.4.1.apk)
- [手机离线版 HTML](BUAA-Memo-Offline.html)
- [版本更新清单](update-manifest.json)

Windows 版解压后双击 `BUAA备忘.exe` 运行，不需要安装 Python。

## 更新方式

电脑端点击窗口底部的“检查更新”。程序会读取本仓库中的
`update-manifest.json`，校验升级包后自动更新并重启。

旧版手机离线 HTML 仍可作为备用方案。

## Android 独立运行

点击电脑端“手机APP”，手机连接同一 Wi-Fi 或电脑连接手机热点后扫描二维码，
即可下载并安装 APK。手机 App 可以独立运行；电脑会自动发现同一局域网中的
手机并同步数据，不需要云端服务器。首次连接需在手机 App 点击“同步”，
然后把这台手机显示的 6 位配对码输入电脑端。未配对设备会收到 401 拒绝。

手机周视图采用竖屏三列课程表，今天、明天和后天的 `00:00–23:59`
会在同一屏幕内完整显示，无需上下或左右滚动。

## 数据说明

备忘录数据只保存在用户自己的电脑和手机中，不会上传到本仓库。
本仓库只保存程序、更新清单和公开的通用离线页面。
